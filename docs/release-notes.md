# Facet v0.1.3

## 复制粘贴与表格

- PPT、Excel 和网页的 HTML 表格优先以可编辑结构粘贴，保留文字、基础格式、列比例、合并单元格和空单元格。
- 表格适应页面或双栏的可用宽度，竖版、横版、纸面 PDF 和 Beamer 使用一致的列比例；已有文件中的超宽表格也适用。
- 合并单元格跨行的区域保持在同一页。列宽继续支持拖动调整。
- 制表符分隔的多行数据可直接粘贴为表格。
- 右键提供保留格式、匹配当前样式、纯文本、Markdown 和图片粘贴；Ctrl+Shift+V / ⌘⇧V 粘贴纯文本。

## 工作空间与编辑

- 左下角设置包含封面、目录层级、导出默认值、分类收藏、说明书与通用偏好；右上角提供导出入口。
- 左侧文件树支持本地文件夹与子目录，顶部显示文件夹名称。
- Ctrl+F / ⌘F 支持全文搜索；公式和括号自动配对，代码跨页连续编号。
- 未保存更改在切换文件或关闭窗口时提供保存、不保存和取消；本机恢复草稿自动保留。
- 首次使用显示说明书，支持阅读 PDF 和打开可编辑示例。

## 下载

Windows x64 安装版：Facet-0.1.3-win-x64-setup.exe。便携版：Facet-0.1.3-win-x64-portable.exe。

macOS 提供 Apple 芯片与 Intel 版本的 DMG 和 ZIP。

## 验证

编辑器完整回归、表格与剪贴板专项、模型与存储测试，以及 Windows 原生剪贴板 smoke test 均通过。

## 已知限制

如果来源应用仅提供图片，粘贴结果为图片。单个跨行合并区域超过整页时，会提示调整内容。Windows 安装包未进行代码签名。
